# 模块变更记录: 全景播放端渐进式 LQIP 贴图管线落地

- **变更日期**: 2026-10-09
- **关联分支**: `feature/20261009_切片渐进式加载`
- **变更类型**: `feat(player)` / 核心渲染管线体验升级

---

## 1. 变更背景
原先场景直接拉取 2.9MB 高清贴图，在弱网环境或切场景时，会有数秒的白屏或转圈等待，无法即刻转动画面。

---

## 2. 具体变更
- **PC 端 (`VrPlayerView.vue`)**:
  - `loadSphereMesh`: 首屏优先载入 `lowResUrl`（约 30KB），0.05s 瞬间解除遮罩并启动开场俯冲飞入动效，后台异步静默升格 2.9MB 高清原图；
  - `switchScene`: 新球体以低清图为材质，立即与旧球执行 1.0s 平滑 Cross-Fade 交叉过渡并解除遮罩，后台静默拉取高清贴图无缝热替换；
  - 引入 `currentLoadToken` 防连击贴图覆盖。
- **移动端 (`VrPlayerViewMobile.vue`)**:
  - 同步落地双阶段 LQIP 贴图管线，大幅改善 4G/5G 弱网下手机端的白屏卡顿；
- **老场景降级**:
  - 无 `lowResUrl` 的历史场景自动降级以 `panoramaUrl` 加载，保证平滑兼容。
